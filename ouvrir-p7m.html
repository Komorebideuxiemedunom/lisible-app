Qu'est-ce qu'un fichier P7M ?

Un document signé électroniquement (enveloppe CAdES/PKCS#7). On en reçoit avec les factures italiennes, les actes notariés ou certains documents administratifs ; Lisible extrait le document qu'il contient.

Comment lire une facture électronique XML ?

Une facture électronique (obligatoire en France à partir de septembre 2026) est un fichier XML illisible tel quel. Dépose-le ici, ou ouvre-le sur iPhone et Mac avec l'app Lisible.

Et les PDF Factur-X ?

Le PDF s'affiche ici ; l'app Lisible lit en plus les données XML cachées dans le PDF Factur-X.
