Aprire un file .msg di Outlook, gratis

Un file .msg è un'e-mail salvata da Outlook. Senza Outlook (Mac, iPhone, Gmail) non si apre. Trascinalo qui: Lisible mostra mittente, destinatari, messaggio e allegati da scaricare.

🔒 Il file viene letto solo nel tuo browser: non viene caricato da nessuna parte.

E-mail Outlook su Mac o iPhone? Lisible apre .msg, winmail.dat ed .eml con un tocco.

Scarica Lisible

Come aprire un file .msg senza Outlook?

Trascinalo in questa pagina, oppure su iPhone e Mac usa l'app Lisible: condividi il file da Mail o File → «Apri in Lisible». Funziona offline.

Posso recuperare gli allegati?

Sì: ogni allegato si scarica, e una fattura allegata (.xml, .p7m) si apre direttamente qui.

E i winmail.dat o .eml?

Lisible apre anche quelli: vedi aprire winmail.dat.

È gratis?

Sì. Nessun account, nessuna pubblicità, i file restano sul tuo dispositivo.
